# 证据与历史观察

证据用于说明“观察到了哪一层”，不能从本地动作推断最终成绩。

## 报告级别

| 类型 | 可以说什么 | 不能推断什么 |
|---|---|---|
| `offline-tested` | 合成输入或本地模拟的测试通过 | 当前平台接口仍有效 |
| `observed-ui` | 目标页面上出现某个文本或样式 | 服务端逐项已保存 |
| `acknowledged` | 请求返回可识别回复 ID 或业务确认 | 内容可读回、参与成绩或不可丢失 |
| `read-back` | 在正确话题或服务端可查询记录中再次看到目标内容 | 后续计分或所有其他条目均成功 |
| `aggregate` | 服务端汇总返回当前数量/时长 | 数量变化必然来自本批某条操作 |
| `unknown` | 缺少证据、格式改变或连接中断 | 成功或失败中的任意一个确定结论 |

这些词是报告约定，具体 CLI JSON 字段以脚本输出为准。目录的 learned 样式属于页面观察；播放器正常结束属于动作观察。两者都不能改写为“服务端最终完成”。

## 新增证据格式

每条新记录至少包含日期、代码版本、系统/运行时/浏览器版本、操作范围、授权边界、预期、实际、原始证据本地位置和可公开的脱敏摘要。明确哪些是失败、未知或未执行。

涉及写入时先一条预览确认，响应含糊先读回，不自动重试。公开记录不包含 Cookie、令牌、真实课程链接、个人成绩或浏览器资料。完整步骤见 [测试说明](../docs/TESTING.md)。
