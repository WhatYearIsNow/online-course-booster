# 故障排查

先记录退出码和结构化结果。连接问题用 `node scripts/doctor.mjs --help` 查看选项，并明确提供自己的本机调试端点或独立浏览器目录。

## 本机连接

| 现象 | 可能原因 | 处理 |
|---|---|---|
| Node / WebSocket 不可用 | 运行时过旧 | 使用 Node.js 22.15.0 或以上版本 |
| 端点拒绝或 404 | Chrome 未启用调试、端口错误、端点不是标准 CDP 服务 | 核对使用者的启动参数；不要假定某个端口一定有效 |
| WebSocket 建立但请求超时 | 旧调试地址、批准窗口、目标无响应或其他客户端影响 | 先只读探活，用户检查浏览器窗口与已连接工具；不自动关闭客户端 |
| DevToolsActivePort 不存在或陈旧 | 指向错误目录，或文件来自先前浏览器运行 | 核对自己选择的独立目录与当前 Chrome；必要时由用户重启 |
| expect-profile 不匹配 | 选错浏览器资料目录或无法取得可核对证据 | 明确核对，不自动复制账户或更改 Local State |
| 页面调用超时 | 页面加载、上下文失效或单页阻塞 | 检查其他页是否响应；保存未知结果，不连续执行写入 |

`--endpoint` 接受本机连接，不需要安装私有 relay、UIA 批准脚本或其他 skill。浏览器要求批准时由用户手动确认。不要把“Chrome 永远只允许一个客户端”作为所有版本的事实。

## 目标身份

- **找不到课程**：确认学习页确在官方域名，course 与 term 是当前课程学期。课程主页不一定是可用学习页。
- **多个匹配页**：提供 `--target`，不选择第一个兜底。
- **学期不符**：切到正确学期或修正参数；不能无视 URL 上的 tid。
- **学校不符**：按实际 URL 核对 school；不使用文档中的合成值。
- **登录不明**：由用户在独立浏览器完成登录。一个 Cookie 存在或 HTTP 200 都不足以证明登录成功。
- **接口返回非 JSON**：可能是登录页、风控、参数或接口改变。只保留脱敏错误，不公开完整响应或反复尝试。

## 讨论与日志

预览不需要浏览器。`--file`、`--rules` 缺失或输入不合法时，先在本地修正。

提交只能使用已确认的 `--plan`。摘要不匹配表示内容、课程、学期或规则可能改变；重新生成计划并审阅，不能复制旧摘要绕过。计划文件已存在时选择新文件名，避免覆盖已确认材料。

如果出现“已有日志”或提交中断：

1. 保留原计划与日志。
2. 人工打开正确课程话题，核对正文与回复 ID。
3. 已读回的条目不再发；无法确定的保留 unknown。
4. 仅对已确认没有提交的条目新建单条计划，并选择新的日志路径，再次确认后执行。

`--journal` 可以指定本地日志，不能作为跳过人工核对的手段。去重仅检查同一日志路径，不是全局事务或平台幂等；换路径、改规则或内容后得到新摘要，仍可能重复提交。请求返回 replyId 只算 acknowledged；不要因此直接宣称已参与成绩。

CDP 关闭或取消只停止 Node 等待，不保证取消网页中已发出的 fetch。网页 fetch 有 10 秒超时，但超时前服务端可能已接收；日志 `uncertain` 必须先人工读回，不能以本地取消为未提交证据。

## 规则、考试与视频

- `grading` 没有读到规则时，人工查看当期公告，不能沿用其他课程的比例。
- `exam` 为 UNKNOWN 时，检查页面实际内容与登录；不要解释为开放，也不开始考试。
- 视频默认扫描是预期行为；只有明确授权并提供 `--execute --rules` 才会执行历史实验。
- 视频网页步骤有界，但断连后可能继续执行，到网页代码 `finally` 的暂停才停止；如需立即停播，由用户查看并控制目标播放器，不将 Node 退出当作回滚。
- 视频 DOM 出现 learned 但汇总不变，或数量变化但时长很少，应分别记录；不要把差异称作正常完成。
- 页面、签名或风控明确拒绝时停止，交由用户按平台正规流程处理。

超星和智慧树只有文档，不能通过反复运行 MOOC CLI 修复。智慧树页面阻塞的根因未确认，详见 [平台说明](../platforms/zhihuishu.md)。

## 离线检查失败

`npm run check` 报告源文件、文档或发布清单问题；`npm test` 报告行为回归。先查看首个具体错误。受限环境拒绝子进程或回环套接字时，记录拒绝并换可运行的测试环境；不能把跳过记为通过。真实平台验证另按 [TESTING.md](../docs/TESTING.md) 执行。
