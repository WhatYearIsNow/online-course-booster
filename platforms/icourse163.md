# 中国大学 MOOC

当前包含的适配器为 `scripts/icourse163.mjs`。命令与参数见 [README](../README.md)。本页说明平台特有的判断边界；2026-10 的旧记录在重构中没有重新连接真实课程验证。

## 课程与学期

支持的学习页形态包括 `/learn/<SCHOOL>-<courseId>`、`/spoc/learn/...` 与 `/mooc/learn/...`。当前学期通常由查询参数 `tid` 表示。同一课程不同学期不能混用 ID。

合成示例：

```text
https://www.icourse163.org/learn/SCHOOL-123456?tid=654321#/learn/content
```

URL、CLI 的 course/term 与选中的 target 必须一致。有歧义先明确 target；不能退回另一个 MOOC 标签页。学校代码从实际 URL 读取，不能写死示例代码。状态与规则检查可能会切换目标页中的栏目，不处理其他标签页。

## 成绩规则先于操作

使用 `grading` 获取成绩栏目文本，并结合当前公告人工核对：

- 各项目权重和截止日期。
- 讨论是回复还是新帖、哪个板块计入、次数与内容要求。
- 视频看完成标记、实际时长还是两者都有要求。
- 测验/考试的实际尝试次数、限时与提交规则。

这些规则是课程配置，不能从平台名称或以前某门课推断。保存到本地的 rules 文件是审阅材料，脚本不会自动证明其来自官方或仍是当前版本。

## 讨论接口与提交证据

历史实现使用 `MocForumBean.addReply.dwr`。请求通过目标课程页面的登录会话发出，凭证只在运行时获取，不应写入预览、输出或仓库。接口并非公开稳定 API，是否可用以当前返回为准。

DWR 是带回调的文本协议。本地解析器只解析受支持的数据形态，不执行响应中的 JavaScript。异常、格式未知或结果含糊要明确失败；正文中出现“exception”等单词不等于异常。返回回复 ID 仅表示 `acknowledged`，还需在对应话题读回正文并确认板块归属。

离线预览绑定课程、学期、规则与回复正文。提交前核对话题在当前课程讨论索引中，无法证明归属时拒绝。写请求不自动重试；提交日志用于识别重复运行与含糊状态。详细恢复方式见 [故障排查](../references/troubleshooting.md)。

2026-10 的历史记录曾观察到某些只读请求无 csrfKey 仍返回数据，以及会话 Cookie 存在但未登录的情况。两者都不能替代当前页面与响应的登录检查。不能由一个 Cookie 是否存在直接断定已登录。

## 视频实验

默认 `videos` 只扫描目录。`--execute --rules <file>` 才启用历史实验的快进与短暂播放流程；这不是平台公开协议，也不保证当前课程接受或计分。

必须保留三层证据：

| 层级 | 可观察内容 | 限制 |
|---|---|---|
| 播放器动作 | 找到视频、seek/play/end 的结果 | 不证明上报已生效 |
| 页面目录 | `learned` 等 DOM 标记 | 不是逐项服务端最终记录 |
| 服务端汇总 | 接口读取的总体数量与时长 | 未必能映射到本批每一个条目，也不等于成绩 |

历史某些课程曾出现“完成数量增长但时长很少”的情况。不能把短暂播放外推为满足实际学习时长，也不能据此断言服务端不校验时长比例。动作失败、标记未变、汇总缺失应保留不同原因。

## 考试与测验

`exam` 只读取考试列表，不开始、作答或提交考试。

| 状态 | 含义 |
|---|---|
| `OPEN` | 列表内存在可见、可用且文本精确为“开始考试”“进入考试”或“继续考试”的操作，没有冲突提示；仍需人工看具体时间与权限 |
| `NOT_OPEN` | 当前页面出现明确的未开放提示 |
| `UNKNOWN` | 页面加载、登录、结构或文案不足以判断 |

条目存在不够。不按课程结束日推算考试日期，不假定尝试次数，不因没有“未开放”字样就认定开放。手动辅助读题时，选项应按实际文字/图标理解，不能假定 A/B 恒等于对/错。批量答题与提交不属于本包当前实现。

## 适配失效时

出现签名拒绝、验证码、风控、异常 HTML 或页面阻塞时停止。保存脱敏错误、退出码与证据，不通过逆向签名、切换身份或重复写请求继续。真实复测标准见 [测试说明](../docs/TESTING.md)。
