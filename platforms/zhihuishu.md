# 智慧树 / 知到：文档范围

**本项目没有智慧树自动化实现。** 登录、验证码、课程读取、视频与讨论均不在当前 CLI 支持范围。

## 入口与历史观察

历史记录涉及门户、课程列表、课程资料页和视频学习页。这些页面可能使用不同会话或路由，门户显示登录不代表其他页面已进入课程。以使用者当前页面与权限为准。

2026-10 的有限环境中曾观察到：CDP 附着时某个 `studyvideoh5.zhihuishu.com` 页面空白且 evaluate 超时；移除相关页面后其他操作恢复。**阻塞现象不能单独证明反调试，更不能确定根因**。同步脚本负载、渲染进程异常等也可能表现相似。本次未复测其他版本、入口或账号。

不要据此声称“所有智慧树视频都无法自动化”，也不要给出能规避阻塞的保证。

## 排障边界

若用户报告阻塞，可先只读检查其他页面是否响应，区分单页与全连接故障。没有授权时不关闭用户页面；由用户自行关闭或恢复目标页。不得连续刷新、换 UA、换入口或修改校验参数以规避明确拦截。

登录与验证码由用户手动完成。旧版中的验证码偏移实验缺少维护与复测，已移除；本包不提供自动验证码流程。

未来若添加平台适配，应先建立只读身份与状态、合成测试、失败停止机制，再讨论写入需求。真实平台证据需要按 [证据说明](../references/verification.md) 记录，不以离线测试或历史记录替代。
