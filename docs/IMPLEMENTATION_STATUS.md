## 真实只读发现与修复

成绩栏目首次读取时，导航已包含 `Grading Criteria`，正文尚未加载。旧等待条件因此提前返回成功，只读到了导航文字。

修复后等待 `.learnPageContent` 中标题之外的正文，再从内容区域读取。明确出现“还没有发布评分标准”等提示时，输出 `state: NOT_PUBLISHED`、退出码 3，不声称已取得评分规则。新增异步正文与未发布规则两个集成回归，Node 22/24 均通过；真实页面复测也得到正确的未发布状态。

当前授权课程观察到：进度接口返回有效结构；考试页明确尚未开放；目录扫描可读。目录扫描没有执行播放，不能据此推断学时或成绩。账户、课程标识、原始页面和原始结果仅保存在被忽略的 `.local/`，不加入公开源码包。

## 超星学习广场实现与实测（2026-10-28）

新增 `scripts/chaoxing.mjs` 与 `scripts/lib/chaoxing.mjs`，复用受管浏览器或显式 CDP 连接：

- 只读：`status` 读取 `window.userId/courseId/classId` 与积分接口；`chapters` 读取分类与知识点。
- 写入：`quiz` 单章、`run` 批量，均先预览并生成摘要，`--submit --confirm DIGEST` 才执行；日志独占，不自动重试。
- 作答策略只有启发式 `--strategy first`，不读题干、不使用答案库；正确率取决于题目分布，不保证达标。
- 摘要绑定课程、班级、章节与题目结构；页面变化拒绝提交。遇到验证码、`操作频繁`、`已在其他页面学习`、`enc 校验失败`、登录失效时停止。

真实实测（Windows / Node 24 / Chrome 155 / 受管 headless）：

1. 登录成功，`status` 读到总积分 1、达标线 800。
2. `chapters` 读到 8 个分类、256 个知识点。
3. `quiz` 预览 5 题（3 判断 + 2 单选），提交后本次成绩 60，广场积分 1 → 7。
4. `run` 批量：跳过已完成章节，逐章作答提交；积分 13 → 21。
5. 重启实例后登录态丢失；鉴权 cookie 均为会话型。

边界：只实现测评作答，未实现视频、阅读、笔记、讨论等计分项；一次通过不代表后续学期或账号通用。启发式作答不保证 800 分。

## 受管浏览器与超星实测（2026-10-28）

借鉴 chatgpt-web 的托管浏览器做法，新增 `scripts/lib/launch.mjs` 与 `scripts/browser.mjs`：独立资料目录、动态回环调试端口、detached 进程，CLI 退出后实例继续运行并可复用。离线回归 207 项通过（新增 19 项）。

真实隔离实测（Windows、Node 24、Chrome 155、headless）：

1. `start --headless` 启动受管实例，`status` 显示独立资料目录与回环端点；日常浏览器未被读取或修改。
2. 在受管实例中打开超星登录页，用用户提供的账号完成手机号 + 密码登录，页面进入 `i.chaoxing.com` 门户。
3. 从课程列表进入 2026 秋季“天津大学形势与政策学习广场”，读取 `window.userId` / `courseId` / `classId`，并调用积分接口得到总积分、达标线与分项规则。
4. `stop` 后重启实例，同一广场页 `window.userId` 为空，页面提示“您尚未报名”。检查 cookie 元数据确认 `_uid`、`_d`、`UID`、`uf`、`vc3`、`p_auth_token` 等鉴权项均为会话型（`session: true`），只有 `fid`、`xxtenc`、`tl` 持久。

结论：受管浏览器本身可稳定后台运行并复用；超星登录态不能跨实例重启持久，这是平台会话型 cookie 的行为，不是受管实现的缺陷。需要跨重启时由平台正规流程重新登录，或保持实例运行。本包仍不包含超星自动化实现，本次只验证浏览器传输与只读页面读取。

## 保留问题与下一阶段
