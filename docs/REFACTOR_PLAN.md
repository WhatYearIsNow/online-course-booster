# 重构与公开准备方案

## 目标与边界

把依赖个人环境的脚本集合整理为可独立审阅、可离线验证的 skill 项目。第一阶段保留中国大学 MOOC 的已存在能力；超星与智慧树保留文档，后续若增加实现再建立独立适配器。项目所有者已选择 MIT 许可证。本次不提交 Git、不创建远端仓库、不发布 npm 包。

## 审计发现

| 原问题 | 影响 | 本次处理 |
|---|---|---|
| 固定个人账户、绝对路径、私有 relay 与批准脚本 | 其他环境无法启动，可能暴露个人配置 | 显式本机连接选项；移除不可公开的默认依赖 |
| 参数解析宽松、标签页歧义与学期不一致 | 容易作用于错误目标 | 严格参数、域名/路径/课程/学期校验；歧义要求 target |
| 讨论去掉 dry-run 就提交 | 预览与真正提交未绑定 | 默认离线预览，完整计划摘要确认，提交日志 |
| 网络中断后可能重复写入 | 重复讨论或结果不明 | 写请求不重试；记录提交意图与结果；人工读回 |
| DOM learned 当作服务端完成 | 夸大验证结果 | 动作、DOM、汇总、最终计分分别报告 |
| 历史经验被写成平台通例 | 无法解释版本与课程差异 | 历史结论单独标注，未知保持未知 |
| 一次性自测和缺少发布元数据 | 回归难复现，包内容不透明 | node:test、CI、清单、打包白名单、贡献文档 |
| 未维护的滑块辅助代码 | 与支持范围不一致，缺少维护边界 | 移除，登录与验证码由用户完成 |

## 实施顺序与验收

实际推进与结果见 [分阶段实施记录](IMPLEMENTATION_STATUS.md)，下列要求不等同于已全部执行。

1. **建立独立项目边界**：只在工作区副本修改，不覆盖已安装 skill；清除个人 ID、成绩、配置路径和 Cookie。验收：公开源文件检查通过，包内没有个人资料目录、凭证或运行日志。
2. **重构协议层**：CDP 客户端与纯解析模块分离；连接探活、请求与整体超时、会话回收、明确关闭行为。验收：本地模拟覆盖请求相关、超时、断线、错误与资源清理，不启动真实 Chrome。
3. **稳定 CLI 契约**：严格选项、课程/学期/标签页校验、结构化结果与退出码。验收：错误参数离线拒绝，候选歧义不静默选择，未登录或不匹配时不写入。
4. **约束写入流程**：讨论预览离线、完整计划摘要确认、话题归属校验与日志；视频默认仅扫描。验收：缺少确认、内容变化、已有任务日志、归属未知均阻断提交；连接中断不自动重试写入。
5. **系统测试与文档标准化**：Node 内置测试、Windows/Linux × 两个 Node 版本的 CI、贡献与安全文档。验收：清单与锁文件一致，测试可离线运行，打包清单可审阅；平台验证与离线验证分列。
6. **真实平台复测**：在使用者单独授权的账号与课程中，先只读，必要时只写一条已确认的讨论。验收：记录日期、版本、条件、响应与人工读回，不公开原始私人材料。此步骤不能由离线 CI 替代。
7. **发布前审阅**：确认 MIT 许可证文件和署名，检查第三方来源、Git 历史、CI 结果、发布清单，再由所有者决定是否公开。本次不自动执行发布。

## 架构取舍

采用零运行时依赖和 Node.js 原生模块，降低安装复杂度；`scripts/icourse163.mjs` 负责命令编排，`scripts/cdp.mjs` 负责连接与会话，`scripts/lib/` 存放可测试的解析与输入处理。暂不为两个仅有文档的平台创建空适配器、统一数据库或插件框架。

输入与输出使用 JSON 文件；运行材料默认放在被忽略的 `.local/`。日志用于防止无意重复提交，不是平台事务：本地磁盘故障、进程中断或用户更改日志仍需人工核验。回复 ID、目录标记均不升级为成绩证据。

## 后续路线

- 真实复测暴露具体失效后，再修复对应选择器或接口；每次附合成回归用例。
- 新平台先支持只读身份与状态，明确证据，再考虑写入流程。
- 接口或输出不兼容时记录迁移说明；首次公开前不承诺稳定 API。
- 只有确实出现共享业务时再抽出通用适配层，避免为假设中的平台扩展增加复杂度。
