## 已验证的关键路径

- CLI → CDP → 页面脚本 → 模拟 HTTP → DWR 回调 → 持久化日志：成功回执、响应丢失、会话缺失、响应过大均有集成用例。
- 目标身份：拒绝相似域名、课程子串、旧学期、未消歧标签；快照后和播放器等待期间同文档切换身份会停止操作。
- 写入边界：预览零连接、完整摘要绑定、主题归属、意图先落盘、日志独占、未知结果不自动重试；输出路径冲突在连接前检查。
- 连接边界：握手失败、协议错误、并发 attach、detach 竞态、迟到响应、错误 session、截止时间、取消及资源清理。
- 证据边界：考试条目本身不证明开放；目录 DOM、播放器动作、服务端汇总、最终计分分别表述。
- 纯协议：DWR 只读取受支持的数据语法，不执行响应代码；正文不能冒充回调，CRLF 不能注入请求行。

对照案例分别为外域 URL 中夹带平台域名、回复正文中的 `id` 冒充回调结果、会话字段 CRLF 请求行注入。仅导入两版纯解析模块，原安装文件校验哈希未变；不运行旧版浏览器连接或命令行。
